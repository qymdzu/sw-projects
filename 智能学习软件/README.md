# 智能学习软件

AI驱动的智能学习平台

## 目录结构

```
docs/requirements/     — 需求分析
docs/research/         — 技术调研
docs/design/           — 系统设计
docs/ux/               — UI/UX 设计
docs/review/           — 代码审查
docs/test/             — 测试
docs/deploy/           — 部署
pseudocode/            — 伪代码（编码 Phase A）
backend/               — Go 后端源码
frontend/              — 前端源码
deploy/                — 部署配置
scripts/               — 工具脚本
tests/                 — 全量测试
```

## 技术栈

- 后端: Go
- 数据库: PostgreSQL
- 部署: Docker
