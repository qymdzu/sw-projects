## 2. 表结构定义

### 2.1 用户表 (users)

| 字段名 | 类型 | 约束 | 默认值 | 说明 |
|:-------|:-----|:-----|:-------|:------|
| id | UUID | PK, DEFAULT gen_random_uuid() | — | 用户唯一标识 |
| name | VARCHAR(100) | NOT NULL | — | 用户昵称 |
| phone | VARCHAR(20) | UNIQUE, NULLABLE | — | 手机号，登录凭证之一 |
| email | VARCHAR(255) | UNIQUE, NULLABLE | — | 邮箱，登录凭证之一 |
| password_hash | VARCHAR(255) | NOT NULL | — | bcrypt 加密后的密码 |
| role | VARCHAR(20) | NOT NULL, CHECK(role IN ('student','teacher','admin','parent')) | 'student' | 用户角色 |
| avatar_url | VARCHAR(500) | NULLABLE | — | 头像 URL |
| parent_id | UUID | FK → users.id, NULLABLE | — | 家长绑定：家长记录的 id |
| created_at | TIMESTAMPTZ | NOT NULL, DEFAULT NOW() | — | 创建时间 |
| updated_at | TIMESTAMPTZ | NOT NULL, DEFAULT NOW() | — | 更新时间 |

**索引：**
| 索引名 | 字段 | 类型 | 说明 |
|:-------|:-----|:-----|:------|
| idx_users_phone | phone | UNIQUE | 手机号唯一 |
| idx_users_email | email | UNIQUE | 邮箱唯一 |
| idx_users_parent_id | parent_id | BTREE | 家长绑定查询 |

### 2.3 知识点表 (knowledge_points)

| 字段名 | 类型 | 约束 | 默认值 | 说明 |
|:-------|:-----|:-----|:-------|:------|
| id | BIGSERIAL | PK | — | 知识点 ID |
| subject_id | BIGINT | FK → subjects(id), NOT NULL | — | 所属科目 |

**索引：**
| 索引名 | 字段 | 类型 | 说明 |
|:-------|:-----|:-----|:------|
| idx_kp_subject_level | (subject_id, level) | BTREE | 按科目层级查询 |
| idx_kp_parent_id | parent_id | BTREE | 树形结构查询子节点 |
| idx_kp_path | path | GIST | 物化路径查询 |

### 2.4 题目表 (questions)

| 字段名 | 类型 | 约束 | 默认值 | 说明 |
|:-------|:-----|:-----|:-------|:------|
| id | BIGSERIAL | PK | — | 题目 ID |
| subject_id | BIGINT | FK → subjects(id), NOT NULL | — | 所属科目 |
| knowledge_point_id | BIGINT | FK → knowledge_points(id), NOT NULL | — | 关联知识点 |
| type | VARCHAR(20) | NOT NULL, CHECK(type IN ('choice','fill','judge','subjective')) | — | 题目类型 |
| difficulty | INT | NOT NULL, CHECK(difficulty BETWEEN 1 AND 5) | 3 | 难度 1~5 |
| content | JSONB | NOT NULL | — | 题目内容（结构化） |

| answer | TEXT | NOT NULL | — | 标准答案 |
| analysis | TEXT | NULLABLE | — | 题目解析 |
| created_at | TIMESTAMPTZ | NOT NULL, DEFAULT NOW() | — | 创建时间 |
| updated_at | TIMESTAMPTZ | NOT NULL, DEFAULT NOW() | — | 更新时间 |

**索引：**
| 索引名 | 字段 | 类型 | 说明 |
|:-------|:-----|:-----|:------|
| idx_q_subject_kp_diff | (subject_id, knowledge_point_id, difficulty) | BTREE | 按科目+知识点+难度筛选 |

### 2.5 学习计划表 (study_plans)

| 字段名 | 类型 | 约束 | 默认值 | 说明 |
|:-------|:-----|:-----|:-------|:------|
| id | BIGSERIAL | PK | — | 计划 ID |
| user_id | UUID | FK → users(id), NOT NULL | — | 所属用户 |
| goal | TEXT | NOT NULL | — | 学习目标描述 |
| start_date | DATE | NOT NULL | — | 计划开始日期 |
| end_date | DATE | NOT NULL | — | 计划结束日期 |
| items | JSONB | NOT NULL | '[]' | 每日计划项 |
| status | VARCHAR(20) | NOT NULL, CHECK(status IN ('active','completed','archived')) | 'active' | 计划状态 |
| ai_generated | BOOLEAN | NOT NULL, DEFAULT false | false | 是否 AI 生成 |
| created_at | TIMESTAMPTZ | NOT NULL, DEFAULT NOW() | — | 创建时间 |
| updated_at | TIMESTAMPTZ | NOT NULL, DEFAULT NOW() | — | 更新时间 |

**items JSONB 结构：**
```json
[
  {
    "date": "2026-07-01",
    "knowledge_point_ids": [1, 3, 7],
    "duration_min": 60,
    "exercises_count": 10,
    "goal": "完成一元二次方程练习"
  }
]
```

**索引：**
| 索引名 | 字段 | 类型 | 说明 |
|:-------|:-----|:-----|:------|
| idx_sp_user_id | user_id | BTREE | 用户计划查询 |
| idx_sp_status | status | BTREE | 按状态筛选 |

### 2.8 错题本表 (mistake_books)

| 字段名 | 类型 | 约束 | 默认值 | 说明 |
|:-------|:-----|:-----|:-------|:------|
| id | BIGSERIAL | PK | — | 记录 ID |
| user_id | UUID | FK → users(id), NOT NULL | — | 所属用户 |
| question_id | BIGINT | FK → questions(id), NOT NULL | — | 错题 |
| knowledge_point_id | BIGINT | FK → knowledge_points(id), NOT NULL | — | 关联知识点 |
| wrong_answer | TEXT | NOT NULL | — | 错误答案 |
| mistake_count | INT | NOT NULL, DEFAULT 1 | 1 | 出错次数 |
| mastered | BOOLEAN | NOT NULL, DEFAULT false | false | 是否已掌握 |
| mastered_at | TIMESTAMPTZ | NULLABLE | — | 标记掌握时间 |
| last_reviewed_at | TIMESTAMPTZ | NOT NULL, DEFAULT NOW() | — | 最近复习时间 |
| created_at | TIMESTAMPTZ | NOT NULL, DEFAULT NOW() | — | 创建时间 |

**唯一约束：** `(user_id, question_id)` 联合唯一，确保同一道错题不重复插入。

**索引：**
| 索引名 | 字段 | 类型 | 说明 |
|:-------|:-----|:-----|:------|
| idx_mb_user_kp | (user_id, knowledge_point_id) | BTREE | 按知识点分类 |
| idx_mb_user_mastered | (user_id, mastered) | BTREE | 按掌握状态筛选 |
| idx_mb_last_reviewed | last_reviewed_at | BTREE | 复习顺序排序 |

## 3. 实体关系说明

| 关系 | 类型 | 说明 |
|:-----|:------|:------|
| users → study_plans | 一对多 | 一个用户可以有多个学习计划 |
| users → study_records | 一对多 | 一个用户有多条学习记录 |
| users → exercise_records | 一对多 | 一个用户有多条练习记录 |
| users → mistake_books | 一对多 | 一个用户有多条错题记录 |
| users → study_reports | 一对多 | 一个用户有多个学习报告 |
| users → users (parent_id) | 一对多 | 一个家长可绑定多个学生 |
| subjects → knowledge_points | 一对多 | 一个科目包含多个知识点 |
| knowledge_points → knowledge_points | 自引用 | 知识点树形结构 |
| subjects → questions | 一对多 | 一个科目包含多道题目 |
| knowledge_points → questions | 一对多 | 一个知识点关联多道题目 |
| questions → exercise_records | 一对多 | 一道题有多条练习记录 |
| questions → mistake_books | 一对多 | 一道题可被多人加入错题本 |
| study_plans → study_records | 一对多 | 一个计划包含多条学习记录 |

## 5. 数据迁移策略

### 5.1 开发阶段

| 方案 | 工具 | 说明 |
|:-----|:-----|:------|
| AutoMigrate | GORM | 开发环境自动建表，快速迭代 |
| 初始种子数据 | GORM Seeder | 预置科目、知识点、示例题目 |

### 5.2 生产阶段

| 阶段 | 工具 | 策略 |
|:-----|:-----|:------|
| MVP 上线 | `golang-migrate/migrate` | 版本化 SQL migration（up/down） |
| 持续迭代 | `golang-migrate/migrate` | 每个变更一个 migration 文件 |
| 数据回滚 | 配套 down 脚本 | 支持上一版本回滚 |

### 5.3 Migration 文件命名规范

```
格式：{version}_{description}.{up|down}.sql
示例：
  000001_create_users_table.up.sql
  000001_create_users_table.down.sql
  000002_create_subjects_table.up.sql
  000002_create_subjects_table.down.sql
```

### 5.4 Migration 执行策略

| 环境 | 执行方式 | 说明 |
|:-----|:---------|:------|
| 开发 | 自动（启动时执行） | `go run main.go migrate` |
| 测试 | 手动 | `migrate -path migrations -database "postgres://..." up` |
| 生产 | CI/CD 脚本 | 部署流水线第一步执行 migration |

## 6. 数据备份与恢复

| 备份策略 | 方案 | 说明 |
|:---------|:-----|:------|
| 全量备份 | `pg_dump` | 每日凌晨 3:00 备份 |
| 备份保留 | — | 保留最近 7 天备份 |
| 备份存储 | 对象存储 | 压缩后上传 OSS/MinIO |
| 恢复测试 | 每月一次 | 在测试环境验证备份可恢复 |
