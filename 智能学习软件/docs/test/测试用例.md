## 1. 用例编号规则

```
TC-{模块}-{序号}
  TC-AUTH-001  → TC-AUTH-012  → 用户认证模块
  TC-USER-001  → TC-USER-008  → 用户模块
  TC-PLAN-001  → TC-PLAN-011  → 学习计划模块

  TC-MIST-001  → TC-MIST-007  → 错题模块
  TC-RPT-001   → TC-RPT-008   → 报告模块
  TC-E2E-001   → TC-E2E-030   → HTTP API 端到端测试（待补）
```

## 2. 用户认证模块（12 用例）

### TC-AUTH-001：注册成功（手机号）

| 项 | 内容 |
|:-----|:-----|
| 模块 | auth |
| 优先级 | P0 |
| 类型 | 单元 / 正常 |
| 关联 DoD | DoD-01 |
| 测试数据 | name="张三", phone="13800138000", password="Abc12345!" |

**前置条件**：mock repo 空

**测试步骤**：
1. 调用 `svc.Register(req)`
2. 校验响应 `resp.User.Name == "张三"`
3. 校验响应 `resp.AccessToken` 非空
4. 校验响应 `resp.RefreshToken` 非空
5. 校验响应 `resp.User.Role == "student"`（默认角色）

**预期**：成功；UserID 非空；密码已哈希（不存储明文）
