## Q-01：AI 能力依赖

| 字段 | 内容 |
|:-----|:------|
| **涉及模块** | 智能推荐题目 (F-10)、计划调整建议 (F-08)、知识图谱薄弱点推荐 (F-23) |
| **问题** | AI 推荐引擎是接入第三方大模型 API（如 OpenAI / 文心一言 / 通义千问）还是自建轻量推荐模型？ |
| **影响** | 直接影响技术方案选型、预算评估和部署架构 |
| **假设** | 当前按接入第三方 LLM API 设计，如需自建模型需额外算力资源 |

## Q-02：题库数据来源

| 字段 | 内容 |
|:-----|:------|
| **涉及模块** | 题库管理 (F-24)、知识点练习 (F-09) |
