## 问题清单

### Q1：关于「老师」角色

| 属性 | 内容 |
|:-----|:------|
| **涉及模块** | 用户角色定义、产品范围 |
| **问题描述** | 原始需求中提到了"老师小程序/练习册线下布置"作为当前痛点背景，但并未明确要求产品中包含「老师端」。请问 MVP 是否需要支持老师角色（布置作业、查看班级学情统计）？如果暂不支持，后续是否有规划？ |
| **建议** | MVP 聚焦学生+家长端，老师端作为 P2/P3 延期。 |
| **状态** | ⏳ 待确认 |

### Q2：关于学科范围的确定

| 属性 | 内容 |
|:-----|:------|
| **涉及模块** | MVP 范围、知识图谱 |
| **问题描述** | MVP 建议先覆盖一个学科（数学）的知识图谱和知识点体系。请问：第一期是否聚焦数学？还是要求多学科同时支持（如数学+英语+物理）？如果多学科，优先级排序是什么？ |
| **建议** | 先做数学一个学科，建立完整闭环后再扩展到其他学科。 |
| **状态** | ⏳ 待确认 |

### Q3：关于 OCR 识别方案

| 属性 | 内容 |
|:-----|:------|
| **涉及模块** | 错题捕获、技术选型 |
| **问题描述** | 错题拍照需要 OCR 识别题面文字（含公式、图形、符号）。是自建 OCR 引擎，还是调用第三方 OCR 服务（如百度 OCR、腾讯 OCR）？对于数学公式（LaTeX）的识别精度要求如何？ |
| **建议** | 调用成熟的第三方 OCR 服务，重点关注公式/符号识别能力，可考虑百度 OCR（数学公式版）或 Mathpix。 |
| **状态** | ⏳ 待确认 |

---

### Q4：关于大模型选型与部署方式

| 属性 | 内容 |
|:-----|:------|
| **涉及模块** | AI 引擎、变式题生成、知识图谱推理 |
| **问题描述** | 变式题生成和知识图谱推理需要调用大模型能力。请问：① 优先使用国内大模型（文心一言/通义千问/DeepSeek）还是国外大模型（GPT-4o/Claude）？② 是否需要私有化部署还是直接调用云端 API？③ 有无成本预算上限？ |
| **建议** | 国内优先（延迟更低、合规更易），调用云端 API（私有化成本过高），可选 DeepSeek/通义千问（性价比高）。 |
| **状态** | ⏳ 待确认 |

### Q5：关于知识图谱的数据来源

| 属性 | 内容 |
|:-----|:------|
| **涉及模块** | 知识图谱、知识框架 |
| **问题描述** | 知识图谱中的知识点体系和前置关系数据从何而来？① 是否对接国家教育大纲（课标）标准知识点库？② 还是由 AI 自动从错题中提取并构建？③ 还是人工梳理？ |
| **建议** | 以国家课标知识点库为基础骨架 + AI 从错题中动态补充边缘节点，两者结合。 |
