## 1. 项目概述

### 1.1 项目背景

智能学习软件是一个面向学生和教师的智能化学习辅助系统。系统利用 AI 技术帮助学生制定个性化学习计划、追踪学习进度、智能推荐学习内容，实现"因材施教"的数字化学习体验。

### 1.2 项目目标

打造一个集**智能学习规划、自适应练习、学习数据分析、错题管理**于一体的学习平台，提升学习效率，减轻教师批改负担，帮助学习者实现个性化学习。

### 1.3 项目范围

| 范围 | 内容 |
|:-----|:------|
| ✅ 做 | 用户管理、学习路径规划、智能练习与批改、错题本、学习数据看板、知识图谱 |
| ⏳ 分期做 | 学习社区互动 (V2.0)、直播授课 (V2.0)、OCR 手写识别 (V2.0) |
| ❌ 明确不做 | 在线考试监考系统、线下教培机构管理系统、教育资源交易平台 |

## 2. 用户角色

| 角色 | 描述 | 核心场景 |
|:-----|:-----|:---------|
| **学生** | 使用本系统进行自主学习 | 制定学习计划、做题练习、查看学习报告、管理错题 |
| **教师** | 创建和管理学习内容、查看学生学情数据 | 上传习题、查看班级学情报告、批改主观题 |
| **管理员** | 系统运维和管理 | 用户管理、内容审核、系统配置 |
| **家长** (P1) | 查看自己孩子的学习情况 | 查看学习报告、接收学习提醒 |

## 5. MVP 范围与分期

### MVP（V1.0 — 核心闭环）

| 模块 | 包含功能 | 说明 |
|:-----|:---------|:-----|
| 用户管理 | F-01, F-02 | 注册登录 + 个人中心 |
| 智能学习规划 | F-05, F-06, F-07 | 目标设定、计划生成、打卡 |
| 智能练习与批改 | F-09, F-10, F-13 | 自动批改 + 智能推荐 + 实时反馈 |
| 错题本 | F-14, F-15, F-16 | 自动收录、分类、重练 |
| 学习数据看板 | F-18, F-19 | 个人报告 + 掌握度可视化 |

**MVP 目标**：学生可以"设定目标 → 获得计划 → 练习做题 → 错题巩固 → 查看报告"，形成完整学习闭环。

### V1.5（重要增强）

- F-03 角色切换、F-08 计划调整建议
- F-11 主观题批改、F-12 试卷生成

- F-22 知识图谱、F-23 薄弱点推荐
- F-24 题库管理、F-25 知识点管理、F-26 学习资料上传
- F-04 家长绑定 + NF-11 家长权限

### V2.0（社区与生态）

- F-27 学习圈动态、F-28 问答互动（学习社区模块）
- F-17 错题导出 PDF
- F-20 开放 API 接口
- 直播授课功能（新）
- OCR 手写识别批改（新）
