## 1. 设计原则

### 1.1 品牌调性

| 维度 | 描述 |
|:-----|:------|
| **定位** | 专业、智能、可信赖的学习伙伴 |
| **调性关键词** | 理性、专注、激励、清晰 |
| **目标人群** | K12 学生 / 大学生 / 教师 |
| **视觉气质** | 现代科技感 + 教育行业温度感 |
| **避免** | 过于卡通 / 过于严肃 / 视觉杂乱 |

### 1.2 设计语言关键词

```
专注 · 智能 · 清晰 · 友好 · 激励
Focus · Intelligent · Clear · Friendly · Motivating
```

### 1.3 三大设计原则

| 原则 | 说明 |
|:-----|:------|
| **专注优先** | 学习场景下减少视觉干扰，让用户聚焦内容 |
| **正向激励** | 通过色彩与微动效营造成就感，鼓励持续学习 |
| **清晰可读** | 字号、行高、对比度严格符合可读性标准 |

## 2. 色彩体系

### 2.1 品牌主色

| 名称 | Hex | RGB | HSL | 用途 |
|:-----|:-----|:-----|:-----|:------|
| **主色 - 智学蓝** | `#4F7CFF` | 79, 124, 255 | 222, 100%, 65% | 主要按钮、链接、关键操作、品牌元素 |
| 主色 - Hover | `#3D6AE5` | 61, 106, 229 | 222, 78%, 57% | 按钮 hover 态 |
| 主色 - Active | `#2D58CC` | 45, 88, 204 | 222, 63%, 49% | 按钮 active 态 |
| 主色 - 浅色背景 | `#EBF1FF` | 235, 241, 255 | 222, 100%, 96% | 选中态背景、Tag 背景 |
| 主色 - 透明度 20% | `rgba(79, 124, 255, 0.2)` | — | — | 图表填充 |

**主色选择理由**：
- 蓝色传递"理性、专业、可信赖" — 符合教育产品气质
- `#4F7CFF` 饱和度适中，避免过于刺眼
- 与白色背景对比度 5.4:1，满足 WCAG AA 标准
- 与教育行业主流蓝色（如猿辅导、作业帮）有差异化，更年轻化

## 6. 动效规范

### 6.1 动效设计原则

| 原则 | 说明 |
|:-----|:------|
| **有意义** | 每个动效都有功能目的（不为了动而动）|
| **快速** | 动效时长控制在 100-500ms，避免拖沓 |
| **可中断** | 用户操作可随时中断动效 |
| **统一曲线** | 同类操作使用相同曲线 |

### 6.2 缓动曲线

| 曲线 | 值 | 用途 |
|:-----|:---|:------|
| **ease-out** | cubic-bezier(0.0, 0.0, 0.2, 1) | 元素进入（淡入、滑入）|
| **ease-in** | cubic-bezier(0.4, 0.0, 1.0, 1) | 元素退出（淡出、滑出）|
| **ease-in-out** | cubic-bezier(0.4, 0.0, 0.2, 1) | 状态切换、位置移动 |
| **spring** | cubic-bezier(0.34, 1.56, 0.64, 1) | 弹性反馈（成功动画）|

### 6.3 动效时长

| 类型 | 时长 | 示例 |
|:-----|:-----|:-----|
| **即时反馈** | 100ms | 按钮 active 态 |
| **小动效** | 200ms | Tab 切换、Tooltip |
| **中等动效** | 300ms | 弹窗出现、页面切换 |
| **大动效** | 500ms | 列表项变化 |
| **特殊** | 800-1500ms | 加载、引导 |

### 6.4 关键动效列表

| 动效 | 触发场景 | 描述 |
|:-----|:---------|:-----|
| 答题反馈 | 提交答案 | 正确：绿色 ✓ 缩放出现；错误：红色 ✕ 抖动 |
| 打卡成功 | 点击打卡 | ✓ 大图标弹出 + 粒子扩散 |
| 标记掌握 | 错题卡片 | 卡片向左滑出 + ✓ 标识 |
| AI 生成计划 | 生成计划 | 三个跳动的圆点循环 |
| Toast 出现 | 操作反馈 | 顶部滑入，3s 后滑出 |
| 加载 | 数据请求 | 骨架屏灰色块渐变 / Spinner 转圈 |
| 空状态 | 无数据 | 插画淡入 + 文字淡入 |

### 6.5 动效降级

| 场景 | 降级策略 |
|:-----|:---------|
| 用户开启"减少动效"（prefers-reduced-motion）| 禁用所有非必要动效，仅保留状态切换 |
| 低性能设备 | 自动缩短动效时长或去除 |
| 旧浏览器 | 自动 fallback 到即时切换 |
