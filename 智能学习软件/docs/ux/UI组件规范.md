## 1. 设计原则

| 原则 | 说明 |
|:-----|:------|
| **原子化思维** | 组件按 原子 → 分子 → 组织体 层级构建 |
| **状态完整** | 每个组件必须定义 default / hover / active / disabled / loading / empty / error 七种状态 |
| **响应式统一** | PC 端使用 Element Plus，移动端 H5 使用 Vant 4，交互逻辑保持一致 |
| **可访问性优先** | 满足 WCAG 2.1 AA 标准，触控目标 ≥ 44×44px（移动端）|
| **设计 Token 化** | 颜色/字体/间距统一从 design token 取值，不硬编码 |

## 3. 组件目录（核心组件）

> 本节定义 MVP 必需的核心组件（≥5 个）。每个组件含：**用途 / 状态枚举 / 尺寸规格 / 布局 / 行为**。

### 3.1 Button（按钮）— 原子

**用途**：触发业务操作的主要交互元素。

**状态枚举**：

| 状态 | 描述 | 视觉变化 |
|:-----|:-----|:---------|
| default | 默认 | 主色填充 / 描边 / 文字按钮 |
| hover | 悬停 | 背景色加深 8% / 阴影提升 |
| active | 点击中 | 背景色加深 15% / scale(0.98) |
| focus | 聚焦 | 2px 主色描边 outline |
| disabled | 禁用 | 灰色填充 + 文字置灰 + cursor: not-allowed |
| loading | 加载中 | 显示 spinner + 禁用点击 + 文字变为"加载中" |
| success | 成功反馈 | 短暂绿色（提交成功场景）|

**尺寸规格**：

| 尺寸 | 高度 (PC) | 高度 (移动) | 内边距 | 字号 | 圆角 |
|:-----|:----------|:------------|:-------|:-----|:-----|
| small | 28px | 36px | 8px 16px | 13px | 4px |
| default | 36px | 44px | 10px 20px | 14px | 6px |
| large | 44px | 52px | 12px 24px | 16px | 8px |

**类型变体**：
- **primary**（主色填充，#4F7CFF）
- **secondary**（白色填充 + 主色描边）
- **text**（无背景，仅文字 + hover 浅灰底）
- **danger**（红色填充，#FF4D4F，用于删除/拒绝）
- **success**（绿色填充，#52C41A，用于确认/通过）

**行为定义**：
- 点击触发业务回调，loading 期间禁用重复点击
- 移动端：touchstart 立即触发 active 态视觉反馈
- 支持 Enter 键触发（focus 态时）
- 支持 `aria-label` 用于无障碍

### 3.2 Input（输入框）— 原子

**用途**：文本/数字输入。

**状态枚举**：

| 状态 | 描述 | 视觉变化 |
|:-----|:-----|:---------|
| default | 默认 | 1px 边框 #DCDFE6 |
| hover | 悬停 | 边框 #4F7CFF |
| focus | 聚焦 | 边框 #4F7CFF + 2px 外发光 |
| filled | 已填写 | 边框 #DCDFE6，文字 #303133 |
| error | 错误 | 边框 #FF4D4F + 下方红色错误文字 |
| disabled | 禁用 | 背景 #F5F7FA，文字 #C0C4CC |
| loading | 校验中 | 右侧 spinner |

**尺寸规格**：

| 尺寸 | 高度 | 内边距 | 字号 | 圆角 |
|:-----|:-----|:-------|:-----|:-----|
| small | 28px | 6px 11px | 13px | 4px |
| default | 36px | 8px 13px | 14px | 6px |
| large | 44px | 10px 15px | 16px | 8px |

**类型变体**：
- text / password / number / email / tel / search

**附属元素**：
- prefix icon（左图标）
- suffix icon（右图标，如清除按钮）
- 校验文字（error 时显示）
- 字符计数（max-length 时显示）

**行为定义**：
- focus 自动滚动到可视区（移动端）
- 支持回车键提交表单
- input 防抖：300ms
- 移动端：弹出对应类型键盘（type=tel 弹数字键盘）

---

### 3.3 Radio / Checkbox（单选/多选）— 原子

**Radio 用途**：单选题选项（练习页、表单）。

**状态枚举**：

| 状态 | 描述 | 视觉变化 |
|:-----|:-----|:---------|
| unchecked | 未选 | 空心圆/方框 + 灰色描边 |
| checked | 已选 | 主色填充 + 中心 icon |
| hover | 悬停 | 描边变为主色 |
| focus | 聚焦 | 2px 主色外发光 |
| disabled | 禁用 | 灰色填充 + 不可点击 |

**尺寸**：PC 16×16，移动 20×20（触控友好）。

**行为定义**：
- 点击切换状态
- 同一 RadioGroup 内互斥
- 移动端：整行可点击（不仅限于 icon）

---

### 3.4 Select（选择器）— 原子

**用途**：下拉选择（知识点筛选、科目选择）。

**状态枚举**：default / hover / focus / open / disabled / error / loading

**尺寸**：与 Input 一致。

**行为定义**：
- 点击展开下拉面板
- 移动端：底部弹出 ActionSheet 而非下拉
- 支持搜索过滤（输入关键字筛选选项）
- 支持键盘上下键导航 + Enter 选中

### 3.5 Card（卡片）— 分子

**用途**：内容容器（计划卡片、统计卡片、错题卡片）。

**状态枚举**：default / hover / active / selected / disabled

**尺寸规格**：

| 尺寸 | 内边距 | 圆角 | 阴影 |
|:-----|:-------|:-----|:-----|
| small | 12px | 8px | 无 |
| default | 16px | 12px | 0 2px 8px rgba(0,0,0,0.06) |
| large | 24px | 16px | 0 4px 16px rgba(0,0,0,0.08) |

**行为定义**：
- hover：阴影加深 + 轻微上移 2px
- 点击：进入对应详情页（卡片整体可点击）
- selected：主色描边 2px

### 3.6 Table（表格）— 组织体

**用途**：数据列表展示（题库管理、用户管理、班级学情）。

**状态枚举**：loading / empty / error / normal

**结构**：

```
┌──────────────────────────────────────────┐
│  筛选区（SearchBar + Filters）            │
├──────────────────────────────────────────┤
│  表头（Header）                            │
├──────┬──────┬──────┬──────┬─────────────┤
│ 列1  │ 列2  │ 列3  │ 列4  │  操作列      │
├──────┼──────┼──────┼──────┼─────────────┤
│ ...  │ ...  │ ...  │ ...  │ 编辑/删除   │
└──────┴──────┴──────┴──────┴─────────────┘
│  分页（Pagination）                       │
└──────────────────────────────────────────┘
```

**尺寸规格**：
- 表头高度：PC 44px / 移动 40px
- 单元格内边距：PC 12px 16px / 移动 8px 12px
- 表头背景：#F5F7FA
- 行高：PC 48px / 移动 56px

**行为定义**：
- 支持列排序（点击表头）
- 支持多选（复选框列）
- 支持行操作（操作列）
- 支持分页（page / page_size）
- 移动端：表格转卡片堆叠（每行展开为一个 Card）
- 空状态：插画 + "暂无数据" + 操作按钮

### 3.7 Modal / Drawer（弹窗/抽屉）— 组织体

**用途**：确认、新增、编辑操作。

**Modal 状态枚举**：default / loading / error

**Modal 尺寸规格**：

| 尺寸 | 宽度 | 高度 | 适用场景 |
|:-----|:-----|:-----|:---------|
| small | 400px | auto | 确认弹窗、简短提示 |
| default | 600px | auto | 表单编辑 |
| large | 800px | auto | 复杂编辑（含多步骤）|
| full | 100% | 100% | 移动端全屏弹窗 |

**结构**：

```
┌─────────────────────────────┐
│  标题                [X]   │  ← Header (可关闭)
├─────────────────────────────┤
│                             │
│       内容区（Body）        │
│                             │
├─────────────────────────────┤
│   [取消]    [确认]          │  ← Footer (操作区)
└─────────────────────────────┘
```

**Drawer 尺寸规格**（侧边抽屉）：
- 宽度：PC 480px / 移动 100%
- 方向：右侧滑入
- 遮罩：半透明黑色 rgba(0,0,0,0.5)

**行为定义**：
- ESC 键关闭（移动端除外）
- 点击遮罩关闭（confirm 类型不关闭）
- 打开时禁止 body 滚动
- 移动端：底部 ActionSheet 替代 Modal

### 3.8 Toast（轻提示）— 分子

**用途**：操作反馈提示（成功/失败/警告/信息）。

**类型变体**：

| 类型 | 颜色 | 图标 | 场景 |
|:-----|:-----|:-----|:-----|
| success | #52C41A | ✓ | 操作成功 |
| error | #FF4D4F | ✕ | 操作失败 |
| warning | #FAAD14 | ⚠ | 警告信息 |
| info | #4F7CFF | ℹ | 一般提示 |

**尺寸规格**：
- 高度：48px
- 内边距：12px 20px
- 圆角：8px
- 阴影：0 4px 12px rgba(0,0,0,0.15)
- 位置：顶部居中（PC）/ 顶部居中（移动）
- 持续时长：3s（可配置）

**行为定义**：
- 自动消失，无需用户操作
- 多条提示堆叠显示
- 移动端：从顶部滑入动画

### 3.9 Loading（加载状态）— 原子

**类型变体**：

| 类型 | 描述 | 场景 |
|:-----|:-----|:-----|
| spinner | 转圈图标 + 文字 | 局部加载（按钮内、卡片内）|
| skeleton | 骨架屏占位 | 列表/页面初次加载 |
| fullscreen | 全屏遮罩 + spinner | 全局等待（如 AI 生成）|

**骨架屏规则**：
- 列表骨架：3-5 行占位条
- 卡片骨架：保留布局结构 + 灰色块占位
- 图表骨架：圆形/折线轮廓占位

### 3.10 EmptyState（空状态）— 分子

**用途**：列表/页面无数据时展示。

**结构**：

```
       [插画/图标]
       
       暂无数据标题
   
   引导描述文字（可选）
   
       [操作按钮]（可选）
```

**尺寸规格**：
- 插画尺寸：120×120px（PC）/ 96×96px（移动）
- 标题字号：16px / 字重 500
- 描述字号：14px / 字重 400
- 整体上下间距：48px

**预置空态**：

| 场景 | 标题 | 描述 | 操作 |
|:-----|:-----|:-----|:-----|
| 错题本为空 | 暂无错题 | 继续保持，你做得很好！ | — |
| 学习报告无数据 | 暂无学习数据 | 开始第一次练习吧 | [开始练习] |
| 计划为空 | 暂无学习计划 | 设定目标，AI 为你定制计划 | [设定目标] |
| 题库为空 | 题库暂无题目 | 添加题目或批量导入 | [新增题目] |

### 3.11 QuestionCard（题目卡片）— 组织体

**用途**：练习页展示题目。

**结构**：

```
┌──────────────────────────────────────────┐
│  [科目标签] [知识点标签] [难度★☆☆☆☆]    │
├──────────────────────────────────────────┤
│  1. 题目内容题干...                        │
│  （支持公式/图片/代码块）                  │
├──────────────────────────────────────────┤
│  ○ A. 选项 A                              │
│  ○ B. 选项 B                              │
│  ○ C. 选项 C                              │
│  ○ D. 选项 D                              │
├──────────────────────────────────────────┤
│           ⏱ 倒计时: 00:30                 │
│              [提交]                        │
└──────────────────────────────────────────┘
```

**状态枚举**：

| 状态 | 描述 |
|:-----|:-----|
| default | 初始展示，可作答 |
| answering | 已选未提交 |
| submitting | 提交中（按钮 loading）|
| correct | 提交后正确（绿色高亮 + 解析展开）|
| wrong | 提交后错误（红色高亮 + 解析展开）|
| timeout | 超时自动提交 |

**尺寸规格**：
- 卡片内边距：24px（PC）/ 16px（移动）
- 选项间距：12px
- 题目字号：16px（PC）/ 15px（移动）
- 选项字号：15px（PC）/ 14px（移动）

**行为定义**：
- 选择答案后"提交"按钮变为可用
- 提交后展示 1.5s 反馈动画，自动进入下一题
- 移动端：选项整行可点击（不仅是 radio）

### 3.12 AnswerFeedbackPanel（答题反馈面板）— 组织体

**用途**：提交答案后展示对错 + 解析。

**结构**：


## 6. 关键交互细节

### 6.1 答题交互

```
用户选择答案 → "提交"按钮可用（蓝色）
   ↓
点击"提交" → loading 转圈
   ↓
服务端批改 → 返回结果
   ↓
正确：绿色 ✓ + 解析展开（1.5s 后自动进入下一题）
错误：红色 ✕ + 解析展开 + 自动收录错题本（1.5s 后自动进入下一题）
   ↓
最后一题：展示"完成"按钮（点击返回首页）
```

### 6.2 错题重练交互

```
进入错题重练 → 加载未掌握错题列表
   ↓
逐题作答（与正常练习一致）
   ↓
全部完成后展示统计：
  - 本次重练 X 道
  - 答对 Y 道（Z%）
   ↓
"标记全部掌握"按钮（仅当全部答对时可用）
   ↓
确认弹窗 → 批量移除错题本 → 提示成功
```

### 6.3 打卡交互

```
点击"打卡"按钮 → 确认弹窗（显示今日完成情况）
   ↓
确认 → 提交打卡 → 成功动画（✓ + 累计天数）
   ↓
3s 后自动关闭弹窗
```

### 6.4 学习计划生成交互

```
进入目标设定 → 选择目标类型 + 填写详情 + 设置每日时长
   ↓
点击"生成计划" → loading 动画（"AI 正在为你生成学习计划..."）
   ↓
若 AI 成功 → 计划预览页（可调整）
若 AI 失败 → 提示"AI 服务暂不可用，已切换规则推荐"
   ↓
点击"确认计划" → 保存 → 跳转首页
```

## 7. 动效规范

### 7.1 动效曲线

| 场景 | 曲线 | 时长 |
|:-----|:-----|:-----|
| 按钮点击反馈 | ease-out | 100ms |
| 卡片 hover | ease-in-out | 200ms |
| Modal 弹入 | cubic-bezier(0.4, 0, 0.2, 1) | 300ms |
| Toast 滑入 | ease-out | 250ms |
| Tab 切换 | ease-in-out | 200ms |
| 页面跳转 | ease-in-out | 300ms |
| 错题标记掌握成功 | cubic-bezier(0.34, 1.56, 0.64, 1) | 500ms |

### 7.2 加载动效

| 场景 | 动效 | 时长 |
|:-----|:-----|:-----|
| 按钮 loading | 转圈 spinner | 持续 |
| 骨架屏 | 灰色块左右渐变 | 1.5s 循环 |
| AI 生成计划 | 三个跳动的圆点 | 1s 循环 |
| 全屏等待 | 居中 spinner + 模糊背景 | 持续 |

### 7.3 反馈动效

| 场景 | 动效 |
|:-----|:-----|
| 答对 | 绿色 ✓ 缩放出现（spring） |
| 答错 | 红色 ✕ 抖动 + 错题本图标飞入（fly-to） |
| 打卡成功 | ✓ 大图标弹出 + 粒子扩散 |
| 标记掌握 | 错题卡片向左滑出 + ✓ 标识 |
