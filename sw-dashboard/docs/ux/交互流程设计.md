## 3. 页面交互流程

### 3.1 全局流程：登录 → 主界面

```
┌──────────┐     输入 Token      ┌──────────────────────────────────┐
│ 登录页面  │ ──────────────────► │        主框架 Layout              │
│          │                     │  ┌────────┐  ┌─────────────────┐  │
│ ┌──────┐ │                     │  │ 导航栏  │  │  内容区 (路由)   │  │
│ │Token │ │   Token 存 localStorage  │ (5入口) │  │                 │  │
│ │输入框│ │ ◄────────────────── ► │  └────────┘  └─────────────────┘  │
│ └──────┘ │                     └──────────────────────────────────┘
│ ┌──────┐ │                           │
│ │登 录  │ │                           ├─ Token 过期 → 跳回登录页
│ └──────┘ │                           │
└──────────┘                           └─ 401 拦截 → 清除 Token → 跳回登录
```

**交互细节**：
1. 用户访问 `http://<tailscale-ip>:8900`，未检测到 Token → 重定向到 `/login`
2. 输入 Token，点击登录 → `POST /api/auth`
3. 验证成功 → Token 存入 `localStorage` → 跳转 `/dashboard`
4. 后续所有请求由 axios 拦截器自动注入 `X-Token` Header
5. 任何 401 响应 → 清除 Token → 跳回登录页

### 3.2 仪表盘页面流程 (默认首页)

```
Dashboard 页面加载
    │
    ├── mounted → fetchDashboard()
    │       │
    │       ├── [加载中] 显示骨架屏 (3 个卡片骨架 + 进度条骨架)
    │       │
    │       ├── [成功] GET /api/dashboard
    │       │       │
    │       │       ├── Gateway 卡片 ← {status, uptime, pid, memory_mb, cpu_percent}
    │       │       │       ├── status === 'active' → 绿色圆点 + "运行中"
    │       │       │       ├── status === 'inactive' → 红色圆点 + "已停止"
    │       │       │       └── status === 'failed' → 红色圆点 + "异常"
    │       │       │
    │       │       ├── 会话统计卡片 ← {total_sessions, active_sessions, ...}
    │       │       │       └── 显示统计数字 + 趋势小标签
    │       │       │
    │       │       ├── Pipeline 进度条 ← {overall_progress, stages[]}
    │       │       │       ├── 整体进度百分比 (环形或线性进度条)
    │       │       │       ├── 阶段列表：各阶段状态图标
    │       │       │       │   ├── completed → ✓ 绿色
    │       │       │       │   ├── running  → ⟳ 蓝色 (旋转动画)
    │       │       │       │   ├── pending  → ○ 灰色
    │       │       │       │   └── failed   → ✗ 红色
    │       │       │       └── 当前阶段名高亮显示
    │       │       │
    │       │       └── Cron 任务面板 ← [{name, schedule, last_run, enabled, last_status}]
    │       │               ├── 启用任务 → 绿色开关 ✓
    │       │               └── 禁用任务 → 灰色开关
    │       │
    │       ├── [失败] 显示错误提示条 (ElAlert)
    │       │       └── 重试按钮 "重新加载"
    │       │
    │       └── [超时] 5s 超时显示降级提示
    │
    └── 自动刷新策略
            ├── 页面可见时每 30s 轮询
            ├── 页面隐藏时暂停轮询 (Page Visibility API)
            └── 手动刷新按钮 ↻
```

## 5. 关键交互细节

### 5.1 未保存修改检测

| 页面 | 检测时机 | 提示方式 |
|:-----|:---------|:---------|
| 存储浏览器 | 编辑模式下切换文件、切换页面 | `ElMessageBox.confirm` "放弃未保存的修改？" |
| 配置管理 | 切换 Tab、切换页面 | `ElMessageBox.confirm` "放弃当前配置的修改？" |
| 全局 | 关闭浏览器标签页 | `window.onbeforeunload` 通用提示 |

### 5.2 加载态策略

| 场景 | 反馈方式 | 持续时间 |
|:-----|:---------|:---------|
| 页面首次加载 | 内容区域骨架屏 (Skeleton) | 直到 API 响应 |
| 组件数据刷新 | 内容区域加载旋转 (Loading Spinner) | 直到 API 响应 |
| 保存/提交操作 | 按钮加载状态 (loading=true) | 直到 API 响应 |
| 懒加载目录树 | 节点图标旋转 | 直到子节点渲染 |
| 日志轮询 | 静默更新，无加载指示器 | 持续 3s 间隔 |

### 5.3 空状态处理

| 页面 | 空状态场景 | 展示内容 |
|:-----|:-----------|:---------|
| 存储浏览器 | 未选中任何文件 | 居中提示 "选择文件以预览" + 文件图标 |
| 存储浏览器 | 仓库为空（无文件） | 提示 "该仓库中暂无文件" |
| 日志查看 | 日志文件为空 | 提示 "暂无日志内容" |
| 日志查看 | 搜索结果为空 | 提示 "未找到匹配内容" |
| 技能浏览器 | 无已安装技能 | 提示 "暂无已安装的技能" |
| Cron 任务 | 无定时任务 | 提示 "暂无定时任务" |

### 5.4 错误状态处理

| 错误类型 | 前端处理 |
|:---------|:---------|
| 401 Token 无效 | `ElMessage.error` → 清除 Token → 跳转 `/login` |
| 403 无权限 | `ElMessage.error("操作被拒绝")` |
| 404 文件不存在 | 内容区显示 404 占位 |
| 413 文件过大 | `ElMessage.warning("文件过大")` |
| 网络断开 | `ElMessage.error("网络连接失败")` + 显示重试按钮 |
| 服务端 500 | `ElMessage.error("服务器内部错误")` |
| 请求超时 (10s) | `ElMessage.warning("请求超时，请重试")` |
