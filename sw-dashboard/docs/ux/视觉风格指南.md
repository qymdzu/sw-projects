# 视觉风格指南 — 翠花集群管理面板 (sw-dashboard)

> 版本：v1.0.0
> 日期：2026-06-03
> 对应阶段：Stage 3 — UI/UX 设计

---

## 1. 设计原则

| 原则 | 说明 |
|:-----|:------|
| **深色优先** | 默认深色主题，降低长时间观察时的视觉疲劳 |
| **轻量简洁** | 去除冗余装饰，只呈现有用的信息 |
| **数据驱动** | 内容为王，视觉为数据服务，不喧宾夺主 |
| **自洽一致** | 遵循 Element Plus Dark 主题规范，不做局部突破 |
| **低带宽友好** | 不依赖外部资源（字体、图标 CDN），纯内网加载 |

## 2. 色彩体系

### 2.1 主题色板

本设计基于 Element Plus 深色主题 (dark) 进行微调，覆盖 Element Plus CSS 变量。


## 3. 字体系统

### 3.1 字体栈

```css
/* 主字体 (代码 + UI 文字) */
font-family: 'JetBrains Mono', 'Cascadia Code', 'Fira Code',
             'SF Mono', 'Consolas', 'DejaVu Sans Mono',
             monospace;

/* Markdown 渲染正文 (技能浏览器) */
--md-font-family: 'PingFang SC', 'Microsoft YaHei',
                  'Noto Sans SC', system-ui, sans-serif;
```

> **设计决策**：统一使用等宽字体作为界面字体。管理面板内容以代码和技术信息为主，等宽字体保证列对齐和代码可读性。Markdown 渲染区使用无衬线中文字体提升长文本可读性。
