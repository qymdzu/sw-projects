# 需求规格说明书 — 翠花集群管理面板

> 版本：v1.0.0
> 日期：2026-06-03
> 来源：公子飞书需求

---

## 1. 产品概述

翠花集群管理面板是一个轻量 Web 管理界面，运行在旧云服务器上，公子通过 ThinkPad 浏览器（Tailscale 内网）访问。用于直观地查看和操作 Hermes 软件开发集群的运行状态、存储结构、配置项。

## 2. 用户角色

| 角色 | 描述 | 权限 |
|:-----|:-----|:------|
| 公子 | 集群管理者 | 全部功能（查看+编辑+操作） |

## 3. 功能需求

### 3.1 仪表盘（P0）

| 功能 | 描述 | 优先级 |
|:-----|:------|:-------|
| Gateway 状态 | 显示 Gateway 运行状态（运行中/停止/异常） | P0 |
| 会话统计 | 今日会话数、消息数 | P0 |
| Pipeline 进度 | 当前项目 Pipeline 各阶段完成状态（绿色进度条） | P0 |
| Cron 状态 | 最近 cron 执行情况 | P1 |
| 模型用量 | 当日 Token 消耗概览 | P2 |

### 3.2 存储结构浏览器（P0）

| 功能 | 描述 | 优先级 |
|:-----|:------|:-------|
| 三库目录树 | 展示 sw-agents-workspace / sw-skills-library / sw-projects 目录结构 | P0 |
| 文件内容预览 | 点击文件在右侧预览 markdown/代码/配置内容 | P0 |
| 文件在线编辑 | 浏览器内编辑并保存文件 | P1 |
| 目录导航 | 面包屑导航 + 展开/折叠树 | P0 |

### 3.3 配置管理（P0）

| 功能 | 描述 | 优先级 |
|:-----|:------|:-------|
| config.yaml 查看/编辑 | 读取和修改 Hermes 配置 | P0 |
| .env 查看（掩码） | 显示 API Key 掩码（如 `deep*********ash`） | P0 |
| CLAUDE.md 编辑 | 在线编辑系统指令文件 | P0 |
| SOUL.md 编辑 | 在线编辑角色定义文件 | P0 |
| Cron 管理 | 查看/启停定时任务 | P1 |

### 3.4 日志查看（P1）

| 功能 | 描述 | 优先级 |
|:-----|:------|:-------|
| 运行日志 | 实时 tail Hermes 日志 | P1 |
| 日志归档 | 浏览历史日志文件 | P1 |
| 关键字搜索 | 搜索日志内容 | P1 |

### 3.5 技能浏览器（P2）

| 功能 | 描述 | 优先级 |
|:-----|:------|:-------|
| 技能目录树 | 展示 skills/ 下所有技能文件 | P2 |
| SKILL.md 内容预览 | 查看技能定义内容 | P2 |

## 4. 非功能需求

| 维度 | 要求 |
|:-----|:------|
| 性能 | 页面加载 < 2s，文件读取 < 1s |
| 安全 | 简单 Token 认证或飞书扫码，配置文件编辑前自动备份 |
| 部署 | 单进程运行，不依赖外部数据库 |
| 兼容性 | Chrome/Firefox/Edge 最新版 |
| 技术栈 | 后端 FastAPI（Python），前端 Vue 3 + Element Plus |

## 5. 业务规则

| 规则 | 说明 |
|:-----|:------|
| 编辑前备份 | 修改配置文件前自动创建 `.bak` 备份 |
| 掩码显示 | API Key 只显示前后 4 位，中间用 `***` 替代 |
| 操作确认 | 配置修改需要二次确认弹窗 |
| 只读模式 | 存储浏览默认为只读，编辑需点击"编辑"按钮进入编辑模式 |
