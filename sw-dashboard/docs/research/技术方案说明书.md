## 4. 文件系统浏览方案

### 4.1 目录树生成 (Python)

使用 `pathlib` 递归遍历目录，构造树结构：

```python
from pathlib import Path
from typing import List, Dict

BASE_PATHS = [
    Path("/home/ubuntu/gitee-software/sw-agents-workspace"),
    Path("/home/ubuntu/gitee-software/sw-skills-library"),
    Path("/home/ubuntu/gitee-software/sw-projects"),
]

async def get_directory_tree(root: Path) -> List[Dict]:
    """递归生成目录树，排除隐藏目录和 node_modules/venv/.git"""
    items = []
    for entry in sorted(root.iterdir(), key=lambda e: (not e.is_dir(), e.name)):
        if entry.name.startswith('.') or entry.name in ('node_modules', 'venv', '__pycache__'):
            continue
        node = {"name": entry.name, "path": str(entry), "type": "directory" if entry.is_dir() else "file"}
        if entry.is_dir():
            node["children"] = await get_directory_tree(entry)  # 延迟加载可使用 hasChildren: true
        items.append(node)
    return items
```

**方案优势**：纯标准库实现，零外部依赖；`pathlib` 跨平台一致；递归结构天然适配 Element Plus `<el-tree>` 组件。

### 4.2 文件读写

```python
import aiofiles

async def read_file(path: str) -> str:
    async with aiofiles.open(path, 'r', encoding='utf-8') as f:
        return await f.read()

async def write_file_with_backup(path: str, content: str):
    """写入文件前自动创建 .bak 备份"""
    p = Path(path)
    if p.exists():
        backup_path = p.with_suffix(p.suffix + '.bak')
        import shutil
        shutil.copy2(p, backup_path)
    async with aiofiles.open(path, 'w', encoding='utf-8') as f:
        await f.write(content)
```

### 4.3 安全措施

- 路径穿越防护：使用 `Path(path).resolve()` 后校验是否在白名单基路径内
- 文件类型白名单：仅允许 `.md/.yaml/.yml/.env/.json/.py/.toml/.txt` 等文本文件编辑
- 二进制文件检测：读取前检查 `path.suffix`，图片/可执行文件只读不编辑

## 5. 日志查看方案

### 5.1 方案对比

| 方案 | 优点 | 缺点 | 推荐度 |
|:-----|:-----|:-----|:------|
| **定时轮询 (REST)** | 实现简单，无持久连接，适合内网 | 实时性一般（1-3s 延迟），无主动推送 | ⭐⭐⭐ 首选 |
| WebSocket 实时推送 | 毫秒级实时 | 连接管理复杂，后端需维护连接池 | ⭐⭐ |
| SSE (Server-Sent Events) | 单向实时，比 WS 轻 | 前端 EventSource API 限制较多 | ⭐⭐ |

### 5.2 轮询实现

```python
# log_service.py
from pathlib import Path

LOG_PATH = Path("/home/ubuntu/.hermes/hermes-agent/venv/var/log")

async def tail_log(file: str = "hermes.log", lines: int = 100) -> str:
    """读取日志文件末尾 N 行（类 tail 命令实现）"""
    log_file = LOG_PATH / file
    if not log_file.exists():
        return ""
    # 从文件末尾倒着读取
    with open(log_file, 'rb') as f:
        f.seek(0, 2)           # 移到文件末尾
        file_size = f.tell()
        buffer = []
        read_size = 0
        chunk_size = 4096
        while read_size < file_size:
            chunk_read = min(chunk_size, file_size - read_size)
            f.seek(file_size - read_size - chunk_read)
            chunk = f.read(chunk_read)
            buffer.insert(0, chunk)
            read_size += chunk_read
            if b'\n' in chunk and len(buffer) > 1:
                # 已读到足够的换行符
                break
        content = b''.join(buffer)
        lines_list = content.decode('utf-8', errors='replace').splitlines()
        return '\n'.join(lines_list[-lines:])
```

### 7.2 .env 掩码显示

```python
import re

def mask_api_keys(content: str) -> str:
    """替换 API Key 为掩码格式：deep********h"""
    pattern = r'(?i)(api[_-]?key|api_key|token|secret)([=:]\s*)([^\s\'"]{8,})'
    def replacer(m):
        prefix = m.group(1)
        sep = m.group(2)
        key = m.group(3)
        if len(key) <= 8:
            return f"{prefix}{sep}{'*' * len(key)}"
        return f"{prefix}{sep}{key[:4]}{'*' * (len(key) - 8)}{key[-4:]}"
    return re.sub(pattern, replacer, content)
```

### 7.3 Cron 管理

```python
import subprocess

async def list_crontab() -> List[Dict]:
    """解析 crontab -l 输出"""
    result = subprocess.run(["crontab", "-l"], capture_output=True, text=True)
    jobs = []
    for line in result.stdout.splitlines():
        line = line.strip()
        if not line or line.startswith('#'):
            continue
        # 简单解析 cron 表达式和命令
        jobs.append({
            "raw": line,
            "schedule": ' '.join(line.split()[:5]),
            "command": ' '.join(line.split()[5:]),
            "enabled": not line.startswith('#')
        })
    return jobs
```

通过读取 Pipeline 工作目录中的状态文件或数据库获取各阶段完成情况。

### 9.3 Cron 状态

读取系统 crontab 和 cron 日志（`/var/log/syslog` 或 `journalctl -u cron`）获取最近执行记录。

## 10. 安全与异常处理

| 场景 | 处理方式 |
|:-----|:---------|
| 路径穿越攻击 | `Path(path).resolve()` 后校验 `is_relative_to(BASE)` |
| 文件不存在 | 返回 404 + `{"detail": "File not found"}` |
| 写入失败 | 捕获 OSError，返回 500 + 错误详情 |
| YAML 解析失败 | `yaml.YAMLError` 捕获，返回 400 |
| Token 无效 | 返回 401 + `{"detail": "Invalid token"}` |
| 大文件读取 | 设置文件大小上限（如 10MB），超出返回 413 |
| 编码错误 | `encoding='utf-8', errors='replace'` 兜底 |

## 13. 技术风险与备选方案

| 风险 | 影响 | 缓解方案 |
|:-----|:-----|:---------|
| 大目录树性能 | 递归生成全树慢 | 改为按需懒加载（仅展开时获取子目录） |
| 异步文件 I/O 兼容 | 旧云服务器可能文件系统较慢 | aiofiles 使用线程池执行，不影响事件循环 |
| CodeMirror 大文件编辑 | 超过 10MB 的文件编辑卡顿 | 限制编辑文件 ≤ 1MB，超大文件只读预览 |
| Tailscale 网络不稳定 | 内网访问延迟或断开 | 前端增加加载状态提示和重试机制 |
| 旧云服务器资源限制 | 512MB 内存可能不够 | 关闭不必要的服务，Uvicorn 设置 `--workers 1` |
