## 3. API 集成测试计划

### 3.1 目标
验证后端 FastAPI 服务的关键端点正常工作，包括认证、授权和数据查询。

### 3.2 测试端点

| # | 端点 | 方法 | 认证 | 预期状态码 | 测试目的 |
|---|------|------|------|------------|----------|
| 1 | `/api/health` | GET | 否 | 200 | 健康检查 |
| 2 | `/api/auth` | POST | 否 | 200 | 登录认证 |
| 3 | `/api/dashboard` | GET | 否 | 401 | 未认证访问拒绝 |
| 4 | `/api/dashboard` | GET | 是 | 200 | 认证后仪表盘数据 |
| 5 | `/api/storage/tree` | GET | 是 | 200 | 存储目录树查询 |
| 6 | `/api/configs/{name}` | GET | 是 | 200 | 配置文件读取 |
| 7 | `/api/logs/tail` | GET | 是 | 200 | 日志查询 |

### 3.3 预期结果
- 公开端点正常响应
- 认证端点正确返回 token
- 未认证请求返回 401
- 已认证请求返回完整数据

## 4. 前端构建验证计划

### 4.1 目标
验证前端代码可成功编译为生产构建产物。

### 4.2 验证步骤
1. 安装依赖（`npm install`）
2. TypeScript 类型检查（`vue-tsc --noEmit --skipLibCheck`）
3. Vite 生产构建（`vite build`）

### 4.3 预期结果
- TypeScript 编译通过
- Vite 构建成功，生成 `frontend/dist/` 目录
- 所有 chunk 生成完毕
