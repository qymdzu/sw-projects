## 1. 概述

翠花面板 **不依赖外部数据库**，所有数据模型均为 Pydantic v2 Schema，用于 API 请求/响应的序列化校验。数据持久化直接来自文件系统、系统命令（systemctl/crontab）和 Gateway 进程状态。

---

## 2. 响应通用模型

### 2.1 API 响应包装

```python
from pydantic import BaseModel
from typing import Generic, TypeVar, Optional, List

T = TypeVar('T')

class ApiResponse(BaseModel, Generic[T]):
    """通用 API 响应包装"""
    success: bool = True
    data: Optional[T] = None
    error: Optional[str] = None

class ErrorResponse(BaseModel):
    """错误响应"""
    detail: str
    error_code: Optional[str] = None
```

## 3. 仪表盘模型

### 3.1 Gateway 状态

```python
class GatewayStatus(BaseModel):
    """Hermes Gateway 进程状态"""
    status: str  # "active" | "inactive" | "failed" | "unknown"
    uptime: Optional[str] = None    # systemd 运行时长

```

### 3.2 会话统计

```python
class SessionStats(BaseModel):
    """今日会话统计"""
```

### 3.3 Pipeline 进度

```python
class PipelineStage(BaseModel):
    """Pipeline 阶段状态"""
    stage_id: int           # 阶段编号 (1-8)
    name: str               # 阶段名称 (需求分析/技术调研/...)
    status: str             # "pending" | "running" | "completed" | "failed"
    progress: float = 0.0   # 0.0 ~ 1.0
    started_at: Optional[str] = None
    completed_at: Optional[str] = None

class PipelineProgress(BaseModel):
    """Pipeline 整体进度"""
    current_stage: int = 0         # 当前阶段编号
    total_stages: int = 8          # 总阶段数
    stages: List[PipelineStage]    # 各阶段详情
    overall_progress: float = 0.0  # 0.0 ~ 1.0
```

## 4. 存储浏览模型

### 4.1 目录树节点

```python
class FileNode(BaseModel):
    """文件系统树节点"""
    name: str                    # 文件名/目录名
    path: str                    # 绝对路径
    type: str                    # "file" | "directory"
    size: Optional[int] = None   # 文件大小（字节）
    mtime: Optional[str] = None  # 最后修改时间
    isLeaf: bool = True          # 是否为叶子节点（文件）
    children: Optional[List['FileNode']] = None  # 子节点（仅目录）
```

### 4.2 文件内容

```python
class FileContent(BaseModel):

    language: str                # 语法类型（yaml/json/markdown/python/text）
    editable: bool = True        # 是否可编辑（文本文件可编辑，二进制只读）
```

## 11. 设计原则

1. **无数据库依赖**：所有数据来自文件系统和系统命令
2. **类型安全**：Pydantic v2 严格校验，所有请求/响应都有 Schema
3. **向后兼容**：API 响应使用 `Optional` 字段，新增字段不影响旧客户端
4. **降级友好**：系统命令超时时返回默认值而非报错
5. **敏感信息保护**：.env 中的 API Key 在 API 响应中自动掩码
