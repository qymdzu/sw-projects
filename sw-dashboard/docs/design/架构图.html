  • • 仪表盘 — Gateway 状态 / 会话 / Pipeline
  • • 存储浏览 — 三库 Tree / 文件预览编辑
  • • 配置管理 — YAML / .env / MD / Cron
  • • 日志查看 — tail / 归档 / 关键字搜索
  • • 技能浏览 — 目录树 + SKILL.md 预览

  • • 3 个 Utils 工具 (路径/命令/日期)
  • • Pydantic v2 Schema 全量数据校验
  • • 自动 OpenAPI 文档 (/docs)

安全与部署

  • • Tailscale 内网 + iptables 白名单
