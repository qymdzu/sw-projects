## 2. 配色方案

### 2.1 主色（Primary）

| 色 | Hex | 用途 |
|:---|:-----|:-----|
| **主蓝** | `#1976D2` | 主操作按钮、链接、强调 |
| **深蓝** | `#0D47A1` | 按下状态、AppBar |
| **浅蓝** | `#E3F2FD` | 主色背景、Badge、提示 |

**理由**：蓝色 = 专注、信任、学习（避免红色刺激、避免绿色"游戏"感）

### 2.2 状态色（Status）

| 色 | Hex | 用途 |
|:---|:-----|:-----|
| 成功绿 | `#34A853` | 答对、完成、保存成功 |
| 警告黄 | `#FBBC04` | 不稳定、待关注 |
| 错误红 | `#E53935` | 未掌握、答错、错误提示（**慎用**）|
| 信息橙 | `#F57C00` | 漏题、待办 |

### 2.3 中性色（Neutral）

| 色 | Hex | 用途 |
|:---|:-----|:-----|
| 主文字 | `#212121` | 标题、正文 |
| 副文字 | `#757575` | 辅助、说明 |
| 浅文字 | `#9E9E9E` | 占位、禁用 |
| 分隔线 | `#E0E0E0` | 卡片边框、分隔 |
| 背景灰 | `#F5F5F5` | 页面背景 |
| 卡片白 | `#FFFFFF` | 卡片背景 |

### 2.4 知识掌握度（核心配色）

| 颜色 | Hex | 含义 | 视觉 |
|:-----|:-----|:-----|:-----|
| 🔴 红色 | `#E53935` | 未掌握 | 实心圆点 |
| 🟡 黄色 | `#FBBC04` | 不稳定 | 实心圆点 |
| 🟢 绿色 | `#34A853` | 已掌握 | 实心圆点 |

**v0.1 重要**：
- 答错**用蓝色**而非红色（避免挫败感）
- 红色**只用于"未掌握"**（知识状态）而非"答错"（动作反馈）

### 2.5 学段主题色（公子 2026-06-06 补充）

| 学段 | 主题色 | Hex | 用途 |
|:-----|:-------|:-----|:-----|
| 小学 | 主蓝 | `#1976D2` | 默认 |
| 初中 | 主蓝 | `#1976D2` | 与小学一致 |
| 高中 | 深蓝 | `#0D47A1` | 更专业稳重 |

**v0.1 简化**：仅切换 AppBar/主按钮色。v0.2 推完整主题切换。

## 3. 字体

### 3.1 字体家族

| 用途 | 字体 | Fallback |
|:-----|:-----|:---------|
| 中文 | PingFang SC | "Noto Sans CJK SC", sans-serif |
| 英文 | SF Pro Text | "Inter", "Helvetica", sans-serif |
| 数字 | SF Pro Rounded | "Inter", system-ui |
| 代码（v0.1 不用）| SF Mono | "JetBrains Mono", monospace |

**v0.1 用系统字体**（Flutter 默认 Roboto + iOS 自动 fallback PingFang）。

### 3.2 字号体系

| 等级 | 字号 | 字重 | 用途 |
|:-----|:-----|:-----|:-----|
| Display | 32pt | Bold | 仅启动页 |
| H1 | 28pt | Bold | 页面主标题 |
| H2 | 22pt | Bold | 区块标题 |
| H3 | 18pt | SemiBold | 卡片标题 |
| Body Large | 16pt | Regular | 题目、列表项 |
| Body | 14pt | Regular | 正文 |
| Body Small | 12pt | Regular | 辅助、说明 |
| Caption | 10pt | Regular | 标签、注脚 |

### 3.3 数字突出

周测答对数、知识点数量等数字用：
- 字号：比正文大 1-2 级
- 字重：Bold
- 颜色：主蓝或状态色（绿/黄/红）

## 5. 动效

### 5.1 动效原则

| 原则 | 实现 |
|:-----|:-----|
| **快** | 时长 200-400ms |
| **自然** | 用 `Curves.easeOutCubic` |
| **不打断** | 不阻塞用户操作 |
| **可跳过** | 加载动画可主动关闭 |

### 5.2 常用动效

| 场景 | 动效 | 时长 |
|:-----|:-----|:-----|
| 页面进入 | 右侧滑入 | 300ms |
| 页面退出 | 右侧滑出 | 300ms |
| 按钮按下 | 缩放 0.95 | 100ms |
| 答对 | ✓ 弹入 + 振动 50ms | 400ms |
| 答错 | → 淡入文字 | 300ms |
| 拍照后 Loading | 旋转 + 文字 | 直到完成 |
| 知识彩虹图 | 柱从 0 长高 | 500ms |
| 周测完成 | 🎉 弹入 + 撒花 | 1.5s |
| Toast 出现 | 上滑 + 淡入 | 200ms |
| Toast 消失 | 下滑 + 淡出 | 200ms |

### 5.3 振动反馈

| 场景 | 振动 |
|:-----|:-----|
| 答对 | 短振 50ms |
| 答错 | 无 |
| 拍照成功 | 短振 30ms |
| 周测完成 | 双振 100ms × 2 |
| 错误 | 短振 80ms × 1 |

v0.1 用 `HapticFeedback.lightImpact()` / `mediumImpact()`。
