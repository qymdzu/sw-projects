## 排除项总结（为什么不用）

| 排除项 | 原因 |
|:-----|:-----|
| Flutter 3.16 | 过老，多个包要求 3.22+ |
| Flutter 3.27 | 太新，主流包适配未稳 |
| Provider | BuildContext 依赖对多模块不友好 |
| Bloc | 学习曲线陡，本项目不必要 |
| GetX | 违反"关注点分离"，Magic 多 |
| Navigator 2.0 | 样板代码多，go_router 更优 |
| auto_route | codegen 慢 + iOS 编译慢 |
| drift | 类型安全但 codegen 慢，SQL 不复杂不必要 |
| isar / Hive | NoSQL，本项目需要 SQL JOIN |
| ObjectBox | 商业许可风险 |
| http（官方）| 无拦截器，统一处理做不了 |
| chopper | codegen 跟 Riverpod 一起慢 |

## 8 维度选型理由（3 层）

### 1. Flutter 3.24 LTS
- 技术：稳定版，主流包兼容
- 团队：公子 Mac 笔记本 + Xcode 15+ 验证过
- 长期：LTS 长期支持，不会被快速替代

### 2. Riverpod
- 技术：compile-time safe，no BuildContext
- 业务：多用户 + 学生/大人模块 + 状态机
- 生态：pub.dev 评分高，Flutter 官方推荐

### 3. go_router
- 技术：声明式路由 + URL 深链
- 业务：启动选身份 → 进入对应模块 流程清晰
- 生态：Flutter 官方推荐（3.16+ 起）

### 4. sqflite
- 技术：SQLite 原生 API
- 业务：需要 SQL 视图隔离（user_id）+ JOIN 查询
- 生态：pub.dev 评分高，DB Browser 可看

### 5. dio
- 技术：拦截器 + 取消 + FormData + 进度
- 业务：调多家云（百度 + DeepSeek + 未来）
- 生态：Flutter 主流 HTTP 库

### 6. image_picker + image + compress
- 技术：覆盖拍照+处理+压缩
- 业务：拍照录入 + 圈画 + 大图压缩
- 生态：pub.dev 评分高，文档全

### 7. fl_chart + graphview
- 技术：折线/柱状/饼 + 知识图谱
- 业务：v0.1 彩虹图 + v0.2 知识图谱
- 生态：pub.dev 评分高

### 8. flutter_local_notifications + secure_storage
- 技术：iOS 本地通知 + Keychain
- 业务：周测/月测推送 + API Key 安全
- 生态：官方推荐

## 抽象层契约确认

| 抽象 | 接口 | 默认实现 | 备选实现 |
|:-----|:-----|:---------|:---------|
| OCR | `OCRProvider` | 百度云教育版 | Mathpix / Apple Vision |
| AI | `AIProvider` | DeepSeek | GPT-4 / Claude / 通义 |
| 通知 | `NotificationProvider` | iOS 本地通知 | - |

**路由配置**（YAML 存在 SQLite + 应用设置）：

```yaml
ocr_routing:
  default: baidu_edu
  rules:
    - when: { question_type: "math" }
      use: mathpix
    - when: { has_handwriting: false }
      use: apple_vision
```
