## 2. 8 维度选型调研

### 维度 1：Flutter 框架版本

| 候选 | 版本 | 状态 | 说明 |
|:-----|:-----|:-----|:-----|
| Flutter 3.24 LTS | 3.24.5 | ✅ 稳定 | LTS，3.24.x 系列长期支持 |
| Flutter 3.27 latest | 3.27.x | 🟡 较新 | Impeller 渲染优化，对 iOS 15 兼容性需验证 |
| Flutter 3.16 | 3.16.x | ❌ 过老 | 多个包已要求 3.22+ |

**推荐**：**Flutter 3.24 LTS**
- 原因 1：LTS 稳定，与主流包版本兼容性好
- 原因 2：公子 Mac 笔记本上 Xcode 15+ + Flutter 3.24 是经过验证的组合
- 原因 3：iOS 15.0+ 适配成熟

**排除**：
- ❌ Flutter 3.27：发布太新，主流包可能未完全适配
- ❌ Flutter 3.16：过老，多个包要求升级

---

### 维度 2：状态管理（State Management）

| 候选 | Stars (pub.dev likes) | 学习曲线 | 性能 | 适用场景 | 推荐指数 |
|:-----|:---------------------|:---------|:-----|:---------|:---------|
| **Riverpod** | ⭐⭐⭐⭐⭐ | 中 | 优 | 中大型 app | ⭐⭐⭐⭐⭐ |
| Provider | ⭐⭐⭐⭐ | 低 | 良 | 小到中型 app | ⭐⭐⭐ |
| Bloc/Cubit | ⭐⭐⭐⭐ | 高 | 优 | 大型/团队 | ⭐⭐⭐ |
| GetX | ⭐⭐⭐ | 低 | 良 | 快速原型 | ⭐⭐ |
| setState | - | 低 | 差 | 简单页面 | ⭐ |

**推荐**：**Riverpod 2.5+**
- 原因 1（技术）：compile-time safe（编译时检查），无 BuildContext 依赖
- 原因 2（业务）：本项目多用户 + 学生/大人两模块 + 状态机复杂，Riverpod 的 Provider 嵌套更适合
- 原因 3（生态）：Flutter 官方推荐之一，pub.dev 评分高

**排除**：
- ❌ Provider：BuildContext 依赖对多模块不友好
- ❌ Bloc：学习曲线陡，本项目不必要
- ❌ GetX：违反"关注点分离"原则，Magic 多
- ❌ setState：状态多了会乱

---

### 维度 3：路由（Routing）

| 候选 | 优 | 缺 | 推荐 |
|:-----|:---|:---|:-----|
| **go_router 14+** | 声明式、深链支持、官方推荐 | 文档偏 Flutter 3.16+ 风格 | ⭐⭐⭐⭐⭐ |
| Navigator 2.0（原生）| 灵活 | 样板代码多、复杂 | ⭐⭐ |
| auto_route | 强类型 | codegen 慢、配置多 | ⭐⭐⭐ |

**推荐**：**go_router 14+**
- 原因 1：声明式路由 + URL 深链，跨平台一致
- 原因 2：本项目"启动选身份"→ "进入对应模块" 流程清晰，go_router 路由树直观
- 原因 3：Flutter 官方推荐（自 3.16 起）

**排除**：
- ❌ Navigator 2.0：样板代码多，学生/大人两模块切换要写一堆
- ❌ auto_route：codegen 慢，build_runner 跟 iOS 编译结合有坑

### 维度 4：本地数据库

| 候选 | 类型 | 性能 | 复杂查询 | iOS 兼容 | 推荐 |
|:-----|:-----|:-----|:---------|:---------|:-----|
| **sqflite** | SQLite 包装 | 良 | 原生 SQL | 优 | ⭐⭐⭐⭐⭐ |
| drift (原 moor) | 类型安全 ORM | 优 | 类型安全 | 优 | ⭐⭐⭐⭐ |
| isar | NoSQL | 优 | 弱 | 良 | ⭐⭐⭐ |
| Hive | 键值对 | 优 | 无 | 优 | ⭐⭐ |
| ObjectBox | NoSQL | 优 | 中 | 良 | ⭐⭐⭐ |

**推荐**：**sqflite 2.3+**
- 原因 1（业务）：本项目需要 SQL 视图隔离（user_id），需要 JOIN 查询（错题 + 变式题 + 知识点），原生 SQL 更直接
- 原因 2（学习）：sqflite API 跟 SQLite 一致，可直接用 DB Browser 看
- 原因 3（生态）：pub.dev 评分高，文档全

**排除**：
- ❌ drift：类型安全虽好但 codegen 慢，本项目 SQL 不复杂
- ❌ isar / Hive：NoSQL 模型，本项目需要 SQL 关联查询
- ❌ ObjectBox：商业许可风险

class OCRFactory {
  static OCRProvider create(String name, Map<String, dynamic> config) {

      case 'apple_vision': return AppleVisionProvider();

    }
  }
}

## 5. 状态机（错题生命周期）

```
[pending_weekly]  -- 答对 -->  [pass_weekly]  -- 月末触发 --> [pending_monthly]
       |                                                                          |
       | 答错 → AI 生成 3 道变式题                                                    | 答对 → [archived]
       ↓                                                                          |
[pending_weekly]（原题 + 变式题下周末继续）                                              |
                                                                                   ↓
                                                                       [pending_weekly]（打回）
```

```dart
// lib/students/state_machine.dart
enum QuestionStatus {
  pendingWeekly,    // 待周测
  passWeekly,       // 通过周测
  pendingMonthly,   // 待月测
  archived,         // 已归档
}

class StateMachine {
  static QuestionStatus next(QuestionStatus current, bool isCorrect) {
    switch (current) {
      case QuestionStatus.pendingWeekly:
        return isCorrect ? QuestionStatus.passWeekly : QuestionStatus.pendingWeekly;
      case QuestionStatus.passWeekly:
        return QuestionStatus.pendingMonthly;
      case QuestionStatus.pendingMonthly:
        return isCorrect ? QuestionStatus.archived : QuestionStatus.pendingWeekly;
      case QuestionStatus.archived:
        return QuestionStatus.archived;  // 终态
    }
  }
}
```
